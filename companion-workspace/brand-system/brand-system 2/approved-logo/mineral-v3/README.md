# ALLIM Mineral Color System V3

The approved ALLIM logo geometry is unchanged. This package introduces a quieter, ownable blue-green digital spectrum.

## Signature palette

- ALLIM Mineral: `#2C7F8C`
- Deep Night: `#071216`
- Warm Ivory: `#F6F3EA`
- Secondary Copper: `#C79A68`
- Signature gradient: `#2B927D → #2E7F98 → #5269A8`

## Recommended use

- Primary digital wordmark: `allim-mineral-gradient-on-night`
- Light interfaces: `allim-mineral-gradient-on-white`
- Solid brand field: `allim-ivory-on-mineral`
- Primary app icon: `allim-aq-ivory-on-mineral-gradient`

PNG, transparent PNG, WebP, favicon PNG sizes and `.ico` packages are included.
