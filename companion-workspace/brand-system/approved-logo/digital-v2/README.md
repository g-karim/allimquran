# ALLIM Digital Color V2

The original approved ALLIM letterforms and embedded QURAN cuts are unchanged.

## Primary digital palette

- Deep background: `#030B0D`
- Electric mint: `#00F5A0`
- Turquoise: `#00E0C6`
- Digital cyan: `#00B8FF`
- Primary gradient: `#00F5A0 → #00E0C6 → #00B8FF`

## Usage

- Use `allim-ai-gradient-on-deep` as the primary digital lockup.
- Use `allim-digital-teal-gradient-on-white` on light surfaces.
- Use `allim-dark-on-ai-gradient` when the gradient fills the background.
- Transparent PNG and WebP files are provided for flexible placement.
- Favicon folders contain PNG sizes from 16 to 1024 px plus `.ico` files.
