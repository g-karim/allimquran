# ALLIM Noor Core V6

Signature direction: a complex turquoise-to-blue spectrum without neon green, gold, or purple.

## Colors

- Ink: `#0A171D`
- Ivory: `#F5F2E9`
- Turquoise: `#329B92`
- Ocean: `#347E98`
- Muted Cobalt: `#5269A6`
- Signature solid: `#357F92`
- Signature gradient: `#329B92 → #347E98 → #5269A6`

## Brand logic

- The approved ALLIM geometry remains monolithic.
- In the full wordmark, color appears inside the carved QURAN letters.
- In the primary app icon, the signature spectrum fills the background behind the ivory A+Q mark.
- A dark alternate icon keeps the field in Ink and places the spectrum inside Q.

PNG, WebP, favicon PNG sizes, and `.ico` files are included.
