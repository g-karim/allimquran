# ALLIM — комплект логотипа

Все варианты собраны из утверждённого изображения без изменения формы букв и внутренних знаков `Q U R A N`.

## Основные версии

- `allim-white-transparent` — белый логотип без фона.
- `allim-black-transparent` — чёрный логотип без фона.
- `allim-emerald-transparent` — зелёный логотип без фона.
- `allim-black-on-white` — чёрный логотип на белом фоне.
- `allim-emerald-on-white` — зелёный логотип на белом фоне.
- `allim-white-on-black` — белый логотип на чёрном фоне.
- `allim-white-on-emerald` — белый логотип на зелёном фоне.

Версии доступны в PNG и WebP, 2400 × 800 px.

## Цвета

- Чёрный: `#0A0D0B`
- Тёплый белый: `#F8F7F2`
- Основной изумрудный: `#087A59`

## Фавикон

Папка `favicons` содержит исходную букву `A` с `Q` в размерах 16, 32, 48, 64, 180, 192, 512 и 1024 px. Также подготовлены файлы `.ico` для сайта.
