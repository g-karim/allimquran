# ALLIM Horizon Color Study V5

This system uses a neutral wordmark and concentrates the signature color in the A+Q app icon and digital accents.

## ALLIM palette

- Ink: `#14242D`
- Ivory: `#F5F1E7`
- Horizon Sand: `#C79A5B`
- Horizon Sea: `#39958F`
- Horizon Blue: `#385E8E`
- Signature icon gradient: `#C79A5B → #39958F → #385E8E`

The approved ALLIM/QURAN geometry is unchanged.

## Recommended hierarchy

- Primary wordmark: Ink on Ivory
- Dark mode: Ivory on Ink
- Primary app icon: Ivory A+Q on the Horizon gradient
- Full-gradient wordmark: experimental accent use only
