# ALLIM Search Intelligence

Internal deployment package for the ALLIM SEO, GEO and AEO control center.

It keeps the existing course metadata fields as the editorial source, adds a
server-rendered search layer to public course routes, stores technical audits,
tracks multilingual answer-engine prompts, records grounded observations and
deduplicates actionable opportunities.

Provider-backed answer-engine measurements are intentionally disabled until
approved server-side credentials are configured and a capped test is reviewed.
The dashboard must show `Not measured` until real observations exist.
