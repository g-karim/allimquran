# Qur’an Companion — рабочий прототип

Mobile-first PWA для проверки продуктовой концепции: чтение Корана, хифз и изучение коранического арабского в одном спокойном интерфейсе.

## Запуск

Не открывайте `index.html` двойным нажатием: адрес `file://` блокирует микрофон и фоновые возможности приложения.

Самый простой способ на macOS — дважды нажать `start_app.command`. Он поднимет локальный сервер и откроет правильный адрес.

В папке проекта выполните:

    python3 -m http.server 4174

Затем откройте:

    http://127.0.0.1:4174/?v=86

Сборка и установка зависимостей не требуются.

Регрессионные проверки последовательностей 33× можно запустить установленным Node.js:

    node tests/linked33-sequence.test.js
    node tests/turkish-wall-sequence.test.js
    node tests/lawh-workflow.test.js

## Что реализовано

- бренд-основа платформы — достоверно переданная дуа Пророка ﷺ за Ибн ‘Аббаса رضي الله عنهما: `اللَّهُمَّ عَلِّمْهُ الْكِتَابَ` («О Аллах, научи его Писанию»), Сахих аль-Бухари 75;
- адаптивные экраны «Сегодня», «Читать», «Хифз», «Изучать», «Тафсир», «Прогресс» и «Настройки»;
- интерфейс на английском, арабском и русском языках; компактный переключатель синхронизирован с языковым выбором главной страницы;
- полноценное переключение LTR/RTL;
- запуск микрофона через базовый совместимый режим системного распознавания речи браузера без экспериментальных phrase hints;
- живая арабская транскрипция, индикатор входного сигнала и пословное сопоставление с выбранным аятом;
- выбор лучшего результата среди нескольких вариантов распознавания с сопоставлением относительно текущего аята;
- рабочее системное озвучивание выбранного аята на арабском с паузой и остановкой;
- заметный локальный AI-наставник: план запоминания, объяснение выбранного слова, совет по повторению и отдельный сценарий «Аят в жизни»;
- в сценарии «Аят в жизни» помощник отличает наблюдение от личного вывода, обнаруживает дублирование заметки в поле действия, проверяет конкретный поступок и момент начала, затем предлагает три разных плана без автоматической подмены слов пользователя;
- перед личным выводом сценарий показывает отдельный корпус «Фавайд аята» с конкретными выводами учёных, границами рассматриваемого отрывка и ссылкой на каждый источник;
- пользователь выбирает один вывод одного учёного как основу; только после этого помощник предлагает план «когда → тогда», не смешивая слова разных авторов и не повторяя пользовательскую заметку;
- 39 доступных сур и 575 проверенных аятов: Аль-Фатиха 1:1–7, Аль-Бакара 2:2–5 и полный Джуз Амма 78–114;
- последовательный переход к следующему аяту или суре;
- настраиваемый автопереход после полностью правильного чтения: переход через одну секунду, отмена и продолжение через границу суры; в хифзе сохраняется трёхсекундный отсчёт;
- настраиваемые звуковые сигналы: мягкий короткий тон после фактического запуска микрофона и двойной низкий тон при обнаруженной ошибке;
- настраиваемая строгая коррекция: приложение останавливается на первом несовпавшем слове, блокирует переход вперёд и принимает продолжение только после правильного повторения отмеченного слова;
- итог чтения без искусственного рейтинга: совпавшие слова, слова для повтора и не сопоставленные фрагменты;
- иммерсивная «Студия фокуса» с полноэкранным мусхафом и закреплёнными инструментами чтения;
- локальные сохранённые аяты и очередь повторения, связанная с результатом чтения;
- голосовая тренировка хифза для любого выбранного аята: правильно распознанные слова открываются строго по порядку, ошибочная карточка остаётся закрытой, а подсказки учитываются отдельно;
- четыре методики хифза: 300×, последовательная 33×, «Турецкая кладка» снизу вверх и цифровой «Ляух» с локальной проверкой фото, ручной сверкой, счётчиками и постоянной библиотекой рукописных страниц на устройстве;
- ручной выбор или объяснимый персональный режим: локальный профиль учитывает чтение без подсказки, подсказки и незавершённые попытки, показывает рекомендацию, но никогда не переключает методику скрытно;
- дневная цель, серия и календарь активности только на основании выполненных действий;
- компактный трёхшаговый гид по единому сценарию обучения;
- безопасный адаптер локального Quran ASR с браузерным fallback;
- интерактивный разбор слов аята 2:2;
- отдельный раздел `تفسير القرآن بالقرآن` по книге «أضواء البيان في إيضاح القرآن بالقرآن»: арабское разъяснение сразу показывается внутри приложения вместе с русским/английским переводом, синхронным выбором аята, ключевыми словами, связями и переходом к первоисточнику;
- корректная атрибуция: авторский текст Мухаммада аль-Амина аш-Шанкыти отделён от продолжения ‘Атыйи Мухаммада Салима для сур 59–114;
- локальный «Исследователь тафсира», который отвечает только по подключённой проверенной карточке и отказывается дополнять источник догадкой;
- локальное сохранение только реальных действий пользователя;
- установка как PWA и базовая офлайн-работа после первого открытия.

## Проверенные данные

Тексты Аль-Фатихи 1:1–7, Аль-Бакара 2:2–5 и полного Джуз Амма 78–114 сверены с Quran.com и официальным Quran.com API. Подробные морфологические пометы для 2:2 основаны на Quranic Arabic Corpus.

Карточки тафсира являются краткими редакционными резюме по «Адва аль-Баян» и ведут к полному арабскому тексту на Quranpedia. Сейчас вручную проверены карточки 1:4, 1:5, 2:2 и 78:1. Для остальных аятов приложение показывает ссылку на источник, но не генерирует неподтверждённое толкование.

Корпус фаваид хранится отдельно от раздела тафсира. Для 92:1 подключены проверенные выводы по соответствующим отрывкам из тафсиров шейха Ибн Усаймина, шейха ас-Са‘ди и раздела «Хидаят аль-аят» в «Айсар ат-тафасир» шейха Абу Бакра аль-Джазаири. Практическая формулировка хранится как отдельная редакционная адаптация и не показывается как цитата или вывод учёного.

## Специализированный Quran ASR

По умолчанию используется живое распознавание браузера. Подготовлен отдельный same-origin сервис для модели `tarteel-ai/whisper-base-ar-quran`; инструкции находятся в `asr/README.md`. Модель и ML-зависимости намеренно не загружаются автоматически: вместе они требуют около 1–2 ГБ и отдельного серверного процесса.

## Ограничения прототипа

- доступность и обработка распознавания зависят от браузера и могут требовать интернет;
- системная служба браузера может обрабатывать звук согласно своей политике; локальный Quran ASR использует временный файл и удаляет его после обработки;
- сопоставление проверяет последовательность слов без огласовок и пока не оценивает таджвид;
- звуковые сигналы синтезируются локально средствами браузера; их можно полностью отключить в настройках;
- системное озвучивание предназначено для прослушивания текста и не является профессиональной записью чтеца; библиотека проверенных записей пока не встроена;
- AI-наставник пока является прозрачным локальным помощником принятия решений: использует выбранный вывод учёного, пользовательское размышление и момент действия, но не выполняет свободную генерацию и не толкует аят; специализированная языковая модель и проверенный retrieval-слой подключаются отдельно;
- «Исследователь тафсира» пока является детерминированным source-bound помощником, а не полной языковой моделью и не сервисом фетв; для полнотекстового поиска потребуется отдельно проверенный/разрешённый корпус и серверный retrieval-слой;
- нет учётной записи и серверной синхронизации;
- статистика сохраняется только в localStorage текущего браузера;
- перед дальнейшим расширением корпуса необходим отдельный процесс проверки текста, лицензий, переводов и лингвистических аннотаций.
