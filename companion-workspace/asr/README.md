# Локальный Quran ASR

Сервис подключает к Qur’an Companion специализированную CPU-модель `tarteel-ai/whisper-tiny-ar-quran` через защищённый same-origin endpoint. Более точную `tarteel-ai/whisper-base-ar-quran` можно включить переменной `QURAN_ASR_MODEL` на сервере с GPU. Аудиофрагмент ограничен 12 МБ, хранится только во временном файле и удаляется после обработки.

## Требования

- Python 3.10 или новее;
- `ffmpeg` для декодирования WebM/M4A;
- около 1–2 ГБ свободного места для ML-зависимостей и кеша модели;
- сама модель занимает около 292 МБ и загружается при первом распознавании.

## Установка

Из корня проекта:

    python3 -m venv .venv
    .venv/bin/python -m pip install -r asr/requirements.txt

Остановите обычный `python -m http.server`, затем запустите единый сервер приложения и ASR:

    .venv/bin/python -m uvicorn asr.server:app --host 127.0.0.1 --port 4174

Откройте `http://127.0.0.1:4174/?v=24`. В настройках станет доступен режим `Quran AI · кораническая речь`.

## Настройка

- `QURAN_ASR_MODEL` — идентификатор совместимой модели Hugging Face;
- `QURAN_ASR_DEVICE` — `-1` для CPU, `mps` для совместимого Apple Silicon или номер CUDA-устройства;
- `QURAN_ASR_MAX_AUDIO_BYTES` — максимальный размер одного фрагмента.
- `QURAN_RUSSIAN_TRANSLATION_ID` — русское издание смыслового перевода: `45` для Эльмира Кулиева (по умолчанию) или `79` для Абу Аделя.
- `QURAN_TRANSLATION_CACHE_SECONDS` — срок серверного кеша перевода; по умолчанию 6 дней, то есть меньше недельного ограничения источника.

Перевод загружается только через same-origin маршрут `/api/quran/translation/{сура}/{аят}`. Клиент показывает автора издания и обязательную атрибуцию Quran Foundation; произвольный `resource_id` отклоняется сервером.

Модель и ключи не загружаются в клиентский JavaScript. Для внешнего развёртывания endpoint необходимо закрыть штатной аутентификацией, ограничением запросов и серверными правилами доступа.
