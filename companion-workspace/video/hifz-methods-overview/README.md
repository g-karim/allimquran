# ALLIM QURAN — обзор новых методик хифза

Русский 16:9 ролик из десяти последовательных сцен о трёх режимах, добавленных в ALLIM QURAN. Финальная длительность — `02:50.27`:

- `33 × связное чтение`;
- `Турецкая кладка` как продуктовая адаптация ALLIM, а не единый канонический турецкий протокол;
- `Цифровой Ляух`, вдохновлённый мавританской традицией письма и сверки.

Финальная сцена показывает персональный план как объяснимую рекомендацию. Выбор методики и фиксированные числа `33`/`300` не меняются без согласия ученика.

## Сборка

```bash
node render_scenes.mjs
python3 build_video.py
```

Озвучка: только мужской премиальный голос Yandex SpeechKit v3 `anton`, роль `neutral`, скорость `0.94`. Начало отделено паузой `1.1` секунды. В синтезе явно зафиксированы ударения «Кора́н», «Кора́на», «Ля́ух» и «ая́т». Скрипт сборки не принимает женский или временный системный голос.

Визуальная система повторяет палитру сайта: тёплая бумага `#f7f5ef`, светлые карточки `#fffefa`, тёмно-зелёные панели `#123d34`, сдержанные бирюзовые и золотые акценты. Используется действующий логотип из `homepage/allim-header-logo.png`.

Кадры фиксированные: масштабирование, сдвиги и дрожание экрана отключены. Между сценами — только мягкое затемнение.

Основной результат: `output/ALLIM-Quran-New-Hifz-Methods-RU-1080p.mp4`.
Для сайта: `output/ALLIM-Quran-New-Hifz-Methods-RU-Web-720p.mp4`.
Субтитры: `output/ALLIM-Quran-New-Hifz-Methods-RU.vtt`.

Проверка финального мастера: H.264 1920×1080, 30 fps; AAC 48 кГц mono; средний уровень звука `-16.9 dB`, пик `-1.2 dB`; декодирование без ошибок, чёрных кадров и пауз длиннее двух секунд нет.

До утверждения мужской озвучки визуальную часть можно проверить отдельно:

```bash
python3 build_visual_proof.py
```

Файл доказательной визуальной сборки специально помечен `VISUAL-PROOF-NO-AUDIO` и не является финальным роликом.
