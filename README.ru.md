# ALLIM Quran

[English](README.md) · [Сайт](https://allimquran.com) · [Участие](CONTRIBUTING.md)

Некоммерческий открытый проект для изучения и заучивания Корана, независимый от
Tarteel AI. Версия `0.1.0` содержит перенесённый прототип сайта и серверного API.
Это начальная версия, а не сертифицированная проверка таджвида.

## Что находится в приложении

- 18 опубликованных страниц: главная, Companion, Academy и блог на трёх языках.
- Один неопубликованный черновик, три формы записи на пробный урок и их DocType.
- HTML/CSS/JS, SEO, редиректы и публичные настройки сайта.
- Логотипы, шрифт, демонстрационные видео, постеры и субтитры.
- Код ASR и API Корана, настройки nginx/systemd, проверки и инструкция развёртывания.

Редактировать страницы нужно в `allimquran/website_content/`. Приложение
синхронизирует эти файлы со стандартными записями Frappe Web Page и Web Form.
Git теперь является источником кода. Изменения в Desk не затираются незаметно:
при расхождении синхронизация останавливается.

Пользователи, заявки, курсы и записи на обучение остаются данными сайта и не
публикуются в репозитории. Прогресс Companion пока хранится в браузере; его ключи
сохранены. Секреты, приватные файлы, аудиозаписи и веса модели не включены.

## Установка и разработка

Нужны Frappe v16, Python 3.14 и установленное на сайте приложение `lms`.
Установка задаёт главную страницу и публичные настройки ALLIM: сначала сделайте
резервную копию либо используйте отдельный тестовый сайт.

```sh
bench get-app --branch main https://github.com/g-karim/allimquran.git
bench --site your-site.localhost install-app allimquran
bench build --app allimquran
bench --site your-site.localhost execute allimquran.setup.preflight
```

ASR запускается отдельно; в окружение Frappe не устанавливаются Torch и модель.
Подробности: [развёртывание](docs/deployment.md), [архитектура](docs/architecture.md),
[проверки](README.md#checks), [ASR](services/asr/README.md).

GitHub Actions пока не активирован: есть шаблон, для его включения требуется
разрешение GitHub на создание workflows.
