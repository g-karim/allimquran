# ALLIM Quran

[English](README.md) · [Сайт](https://allimquran.com) · [Участие в разработке](CONTRIBUTING.md)

ALLIM Quran — некоммерческий проект для изучения и заучивания Корана с участием
сообщества. Мы хотим объединить практику чтения, хифз, повторение, коранический
арабский и объяснения с указанием источников. Проект независим от Tarteel AI.

## Текущее состояние

Версия `0.0.1` — начальная основа Frappe-приложения: метаданные пакета, модуль
`ALLIM Quran`, структура для будущего кода и ресурсов, документация и шаблон CI.

Страницы действующего прототипа пока находятся в БД Frappe, а распознавание речи
работает в отдельном сервисе. Этот код ещё предстоит перенести в репозиторий.
Установка текущей версии регистрирует приложение, но не создаёт интерфейс
Companion, курсы или ASR и не переключает главную страницу сайта.

## Установка

Нужен отдельный bench для разработки с Frappe **version-16** и **Python 3.14**.
Выполните из каталога bench, заменив `your-site.localhost` на свой тестовый сайт:

```sh
bench get-app --branch main --skip-assets https://github.com/g-karim/allimquran.git
bench --site your-site.localhost install-app allimquran
bench --site your-site.localhost list-apps
```

Для начальной версии не нужны LMS, платёжные приложения или модели распознавания.
Сборка frontend пока отсутствует.

## Разработка

Структура каталогов и команды проверки описаны в [README.md](README.md).
Текущая архитектура и направление переноса — в [docs/architecture.md](docs/architecture.md).
Шаблон CI — [`.github/checks.yml.example`](.github/checks.yml.example). Для его
включения нужно опубликовать файл как `.github/workflows/checks.yml` с правом
создания workflow. В исходной авторизации этого права нет; CI пока не активен.

Принимаем issues и pull requests на русском и английском. Начать можно с
[CONTRIBUTING.md](CONTRIBUTING.md). Ближайший этап — перенос существующего
прототипа в версионируемые файлы, затем серверное сохранение прогресса,
проверка качества распознавания и реальные учебные программы.

Код репозитория распространяется по [MIT License](LICENSE). Тексты, переводы,
тафсир, аудиозаписи, шрифты и модели сохраняют собственные условия использования
и требования к указанию источников.
