**Заготовки из PR #1 для этапа подготовки**

Эти файлы выделены из работы GRAISS (PR #1, commit `f94fb7fda236ace2a00921c1e96292e1a1282845`). Они не подключены к страницам, API, схемам или hooks приложения. Это материал для следующих этапов, а не готовое хранение аккаунта.

- `reading-journal-v1.cjs`: чистые функции `fresh`, `validate`, `summary` для старого формата журнала. Сохранены уникальное покрытие страниц, повторный объём, циклы и прошлые хатмы. Исключены UI, доступ к браузерному хранилищу, синхронизация и подсчёт награды. Историческое поле `letters` принимается валидатором для совместимости, но не участвует в итогах.
- `reading_journal_v1.py`: исходный чистый валидатор PR, канонизация JSON, digest и решение о повторе/конфликте последней операции. Файл перенесён без изменения. Он не импортирует Frappe и не выполняет записи.

Формат v1 — кандидат для импорта старого журнала, если он существует у пользователя. Он не принят как будущая серверная модель всего прогресса. Клиентский валидатор слабее серверного; правила нужно согласовать перед использованием с недоверенными данными. Диапазоны и форма ключа не доказывают, что слово относится к указанной странице или что чтение действительно состоялось.

`decide` распознаёт повтор только последней операции. Полный протокол синхронизации, изоляция аккаунтов, несколько вкладок и восстановление после выхода здесь не реализованы. Старые сетевые endpoints и `reading-sync.js` намеренно не извлечены: их нужно заменить после проектирования общего хранения.
