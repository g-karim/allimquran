# Проверка на настоящем iPhone/iPad

Обновление 18 октября 2026: сайт опубликован по HTTPS, гонка CSRF исправлена,
проверки Playwright WebKit 26.5 прошли на точных версиях сервера. Проверка на
физическом устройстве всё ещё **не выполнена**. Два временных аккаунта выпуска
удалены; для этого отдельного прохода нужны новые тестовые аккаунты. Ниже сохранены
исходные условия и сценарии проверки.

Статус 15 сентября 2026: **не выполнена**. Нет результата с физического устройства
и опубликованного изолированного HTTPS-стенда для него. `http://127.0.0.1:18143`
на Mac недоступен по этому адресу с телефона. Проверку нужно провести на
согласованном тестовом сайте с двумя синтетическими аккаунтами A/B после
исправления гонки CSRF; личные аккаунты и рабочие пользовательские данные
для неё не нужны.

Перед началом записать модель устройства, версию iOS/iPadOS и Safari,
адрес стенда, точный Git-коммит и режим: обычная вкладка или приложение с
домашнего экрана. Приватный режим и приложение с домашнего экрана, если оно
предлагается сайтом, проверяются отдельно: у них может быть другое хранилище.

| Действие | Ожидаемый результат |
|---|---|
| Гостем добавить одну ручную запись журнала. Полностью выгрузить Safari, открыть сайт снова при включённой сети | Запись остаётся; режим хранения — на устройстве |
| Войти в A, отказаться от переноса гостевой истории | Аккаунт открывается со своей историей; гостевая запись не попадает в аккаунт |
| В A добавить другую запись и дождаться «Сохранено в аккаунте». Проверить A в другом браузере | Одна и та же запись доступна с сервера, без дубля |
| На уже загруженной странице A отключить сеть и добавить ещё одну запись | Запись видна с ожиданием отправки, без ложного подтверждения серверного сохранения |
| Оставить Safari в фоне и заблокировать устройство минимум на 2 минуты, затем вернуться и включить сеть | Очередь сохраняется, запись автоматически отправляется ровно один раз |
| Снова создать offline-запись A, выйти, включить сеть и войти в B | В B нет истории и очереди A; гостевые записи не подменены данными A |
| Вернуться в A | Его неотправленная запись восстанавливается и доходит до сервера один раз |
| Перейти RU → AR, открыть журнал, форму даты и диапазона; показать клавиатуру, повернуть экран | Поля и кнопки достижимы прокруткой, нет горизонтального переполнения, арабский интерфейс имеет правильное направление |
| Открыть две вкладки свежего входа; затем выйти в одной | Обе вкладки открываются без сбоя CSRF; после выхода личные формы и данные скрываются |
| Очистить локальную копию тестового A, затем войти снова | Подтверждённая серверная история восстанавливается; очистка устройства её не удаляет |

Автономная очередь на загруженной странице не означает, что весь сайт, тексты,
аудио и распознавание запускаются без сети после холодного старта.

Для каждого пункта записать «пройден / ошибка / не проверен», наблюдение и время.
При ошибке достаточно описания экрана и действий; не присылать пароли, cookie
или содержимое личных аккаунтов. Итог без заполненных результатов не считать
приёмкой iOS.
