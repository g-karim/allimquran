## Что определено на этапе 2

- Гость сохраняет на устройстве; после входа новые изменения автоматически идут в аккаунт. Перенос старой гостевой истории требует отдельного выбора.
- Учебные записи разделены по типам. Одно чтение — устойчивое событие; весь прогресс не передаётся одной заменяемой JSON-книгой.
- Повтор доставки не увеличивает счётчики. Конфликтующие тексты и цели сохраняются для выбора, удалённые записи защищены от старых offline-запросов.
- Очистка устройства не вызывает удаление аккаунта. Выход и смена пользователя изолируют кэш/очередь, а поздние ответы проверяют исходного владельца.
- Неотправленные данные после выхода сохраняются для того же аккаунта до доставки или явного удаления; скрытого срока потери offline-работы нет.
- Старые пересекающиеся суммы не складываются автоматически. Импорт честно показывает неподдерживаемые и спорные элементы и сохраняет исходную локальную копию.
