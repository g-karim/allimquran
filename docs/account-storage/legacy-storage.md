**Вложенный прогресс хифза**

`heartMushaf.units["surah:ayah"]`, нормализация в `learn/javascript.js:2699`:

- `weekCounts`: три счётчика этапов по 100; текущая сумма вычисляется из них.
- `accepted`: более старый суммарный счётчик. При отсутствии `weekCounts` текущий клиент распределяет его по этапам; не складывать оба представления.
- `daily`: дата → количество повторений.
- `maintenanceCount`, `maintenanceLevel`: поддерживающее повторение.
- `startedAt`, `lastAcceptedAt`, `completedAt`, `nextReviewAt`: известные даты.
- `permanent`: текущее состояние закрепления.

`heartMushaf.pages["pageNumber"]`, нормализация в `learn/javascript.js:2734`:

- `pageNumber`, `connectedAttempts`, `connectedReviews`.
- `lastConnectedAt`, `sealedAt`, `permanent`.

Эти объекты содержат состояние и некоторые даты, но не полный журнал событий. При миграции нельзя из счётчика 200 создать 200 якобы известных чтений. Сначала сохраняется исходный агрегат, новые действия получают собственные ID по будущему контракту.

**Записи размышлений**

`lifePractice.entries[]` создаются в `saveLifePractice` (`learn/javascript.js:3947`) и обновляются также в `completeLifeEntry` (`3557`):

- `id`, `createdAt`, `updatedAt`; ID старого клиента вида `life-<Date.now()>` не гарантирует глобальную уникальность между устройствами.
- `verseKey`, `reference`, `reflection`, `action`.
- `fawaidId`, `fawaidScholar`, `fawaidBenefit`, `fawaidSourceUrl`: сохранённый контекст выбранного материала.
- `trigger`, `reviewAt`, `completed`, иногда `completedAt`.

Часть полей может отсутствовать; считать все записи созданными новой версией нельзя. Текст заметки, локализованные подписи и выбранный источник должны пережить перенос без автоматического переписывания.

Если старая sync-запись уже указывает аккаунт A, её журнал нельзя автоматически предложить пользователю B как гостевой. Для записей без владельца нужен однократный выбор переноса, исходная копия и защита от повторного импорта. Неизвестные поля сохраняются в исходной резервной копии и требуют отдельного решения; автоматическая отправка всего localStorage исключена.

Курсы, зачисления, заявки и права доступа уже принадлежат существующей базе Frappe/LMS. Они не восстанавливаются из локальных счётчиков и не дублируются новым журналом. Технические состояния микрофона и текущего запроса, кэши текста, шрифтов и аудио не становятся частью аккаунта.
