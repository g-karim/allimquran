## Исправление тестов

У исходного импортёра тест был указан только в `Course Lesson.quiz_id`.
В проверенной LMS это показывало тест, но проверка `get_quiz_progress` искала
макросы/блоки в содержимом урока; обратная ссылка `LMS Quiz.lesson` также оставалась
пустой. Урок мог завершиться до теста, а успешная попытка не связывалась с уроком.

Теперь каждый урок содержит ровно один штатный `{{ Quiz("id") }}` в Markdown.
`quiz_id` и EditorJS `content` остаются пустыми, поэтому второго экземпляра теста
не появляется. После создания уроков импортёр заполняет у каждого теста обе ссылки:
`course` и `lesson`. Вставка идёт в порядке, допустимом для нативных Link-полей.

При реальной установке также исправлены два несоответствия исходного импортёра:
`LMS Quiz Question.question_detail` хранит обычный текст, а не HTML вопроса;
ссылки на практику локальны для сайта и содержат канонические HTML-экранированные
разделители URL. Это сохраняет строгую проверку результата чтением из БД.
Передаваемый граф копируется до нативных вставок, чтобы Frappe не менял эталон
для последующего сравнения.

## Явный импорт

Данные находятся в `allimquran/youth_curriculum/courses.json`, команда —
`allimquran.youth_curriculum.execute`. На сайте должны быть установлены LMS/ALLIM
и существовать активный преподаватель с ролью `Course Creator` или `Moderator`.
У вызывающего пользователя должны быть обычные права создания записей LMS.

Сначала просмотр плана:

```sh
bench --site your-site.localhost execute allimquran.youth_curriculum.execute \
  --kwargs '{"instructor":"teacher@example.org"}'
```

Создание черновиков:

```sh
bench --site your-site.localhost execute allimquran.youth_curriculum.execute \
  --kwargs '{"instructor":"teacher@example.org","apply":true}'
```

Ожидается `create=164`: три курса, 14 глав, 43 урока, 43 теста и 61 вопрос.
Повтор с тем же преподавателем возвращает `existing=164, create=0`.
Курсы получают `published=0`, `paid_course=0`, `enable_certification=0`;
уроки не включаются в публичный preview. Обычные install/migrate не запускают импорт.

Совпадение названий с чужими курсами, прежний пакет `ALLIM-C01`, неполное состояние,
опубликованный курс или изменения управляемого содержимого останавливают команду.
Автоматической перезаписи нет. Ошибка вставки откатывает импорт до savepoint;
окончательный commit принадлежит вызывающей команде. Существующие материалы
преподавателя сначала нужно согласовать отдельно.

18 октября при подготовке выпуска найден существующий черновик с названием
первого курса и собственными идентификаторами. Для сохранения его 25 уроков
импортёр принимает явный `title_suffix`, например `" · программа 2026"`.
Он меняет только названия трёх новых черновиков; исходный пакет, стабильные ID,
ссылки тестов и защита существующих записей сохраняются. Суффикс нужно передавать
и при повторе команды. Без него совпадение с существующим названием по-прежнему
останавливает импорт. Это отдельная редакция для проверки преподавателем,
существующий курс не переименовывается и не перезаписывается.

На точном окружении production (Frappe 16.51.0 / LMS 2.62.1) также проверено
отсутствующее поле `LMS Quiz.enable_proctoring`: пропускается только это удалённое
поле с принудительным значением 0, с явным указанием в `omitted_fields`. Отсутствие
обязательной ссылки `lesson` по-прежнему останавливает весь план. Все 164 записи
созданы и повторно сверены на восстановленной копии сайта, 43 неотвеченных теста
считаются незавершёнными. Семь браузерных сценариев со штатной LMS прошли;
в этой версии её начальная кнопка называется `Start`, в ранее проверенной —
`Start Quiz`. Сценарий поддерживает обе подписи, проверки прогресса не изменены.

Прогресс и попытки принадлежат вошедшему пользователю и хранятся в штатных
серверных `LMS Enrollment`, `LMS Course Progress`, `LMS Quiz Submission`.
Обычный ученик не получает заметки преподавателя или доступ к этим черновикам.

## Проверка

Выделенный локальный сайт `allim-youth.localhost`, отдельная БД `allim_youth_20261017`:
Frappe 16.26.3, MariaDB 11.8.8, Payments и полная LMS. Проверен зафиксированный
LMS commit `0cd844e212e9818feacdbcdfd44677f7504dea28` из пакета автора;
его `lms.__version__` — `2.45.2`. Фронтенд собран из этого исходника.
Это проверка данной версии схемы/API; перед импортом на другом сайте dry-run
должен подтвердить его фактическую схему и преподавателя.

- `tests/test_youth_curriculum.py`: граф ссылок, единственное размещение теста,
  обратные ссылки, ответы, безопасные флаги, возрастные задания и защита правок.
- `scripts/check_youth_curriculum_site.py`: реальные DocType и обычная роль автора;
  dry-run без вставок, откат прерванного импорта, совпадение названий, неполный пакет,
  повторяемость, защита редактированного/опубликованного содержимого. Штатная функция
  LMS считает все 43 неотвеченных теста незавершёнными.
- `scripts/check_youth_curriculum_browser.cjs`: настоящий собранный LMS в Chrome
  через HTTP/Frappe/MariaDB, без подмены ответов курсов, тестов или прогресса.
  Ученик получает один тест, неверный ответ не закрывает урок, успешная повторная
  попытка открывает второй урок. Прямой вызов сохранения не обходит тест. После reload
  и в чистом мобильном профиле прогресс сохраняется. Другой ученик без зачисления
  не получает тест; заметки преподавателя скрыты. Автор может открыть исходный черновик.

Для прохождения обычным учеником создана отдельная опубликованная копия двух уроков
с идентификаторами `allim-y1-youth-fixture` / `allim-y1-fixture-*` только на тестовом
сайте. Все три исходных курса остались неопубликованными. После браузера сравнен
полный хэш 164 исходных записей: он не изменился. В тестовой копии ровно один
завершённый урок и две попытки первого теста: 0% и 100%; двойного зачёта нет.

Браузерный сценарий запускается после подготовки свежего fixture сайта и отчёта
`check_youth_curriculum_site.py`; оба скрипта принимают только выделенные локальные
фикстуры и синтетических пользователей.

```sh
ALLIM_PLAYWRIGHT=/absolute/node_modules/playwright \
ALLIM_TEST_URL=http://127.0.0.1:18643 \
ALLIM_TEST_CREDENTIALS=/private/fixture-credentials.json \
ALLIM_YOUTH_REPORT=/private/site-report.json \
node scripts/check_youth_curriculum_browser.cjs
```

Весь Python-набор: 146 тестов, 145 прошли, один прежний opt-in пропущен.
Node: 72 теста прошли. Семь браузерных групп прошли без необработанных JS-ошибок.
Ruff, форматирование, синтаксис JavaScript, сборки приложения и фронтенда LMS пройдены.
JSON курса присутствует в wheel вместе с импортёром.

Логи, снимки и отчёты прогона: `/tmp/allim-youth-20261017/`.
Тестовая конфигурация, пароли и БД в Git не включены. Production не обновлялся.
Перед публикацией требуется проверка преподавателем арабских примеров, ссылок
и устных критериев. Письменные тесты проверяют узнавание/понимание; произношение
и таджвид подтверждаются преподавателем отдельно.
