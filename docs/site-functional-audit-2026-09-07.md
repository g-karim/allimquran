# Аудит ALLIM Qur’an — 7 сентября 2026

## Краткий вывод

Это уже работающий прототип самостоятельной практики и отдельный сайт-кабинет,
но ещё не полноценная онлайн-академия и не проверка произношения уровня Tarteel.
Рабочие интерфейсы, реальные серверные данные и заготовленные демонстрации нужно
различать. Новая `/teacher` — закрытая исследовательская разметка добровольных
записей, а не система личных домашних заданий и обратной связи конкретному ученику.

Проверены исходники ALLIM и установленной Frappe/LMS, метаданные/агрегаты базы,
HTTP-маршруты, браузер Chrome на ширинах 1440 и 390, а после установки — новый
Website User с ролью проверяющего. Чужие личные записи не прослушивались.
Формы заявок не отправлялись; реальный микрофон в этом аудите не использовался.

## Личный кабинет и вход

- Собственный кабинет **уже находится на сайте**: `/academy`, не Desk.
- Кнопка гостя ведёт на `/login?redirect-to=%2Facademy`. Вход по такой ссылке
  предназначен для возврата в Academy.
- При обычном входе без адреса возврата новый пользователь получил `home_page:
  /lms`. Причина — выбор приложения через `frappe.apps.get_default_path()`,
  а не отсутствие кабинета ALLIM. Глобальная маршрутизация в этом изменении не
  перестраивалась.
- В существующем JS кнопка вошедшего пользователя указывала на **`/lms/profile`**,
  которого нет в роутере установленной LMS. HTTP 200 возвращал оболочку SPA, не
  работающий профиль. Ссылка исправлена на **`/lms/user/<username>`** и проверена.
- Проверяющему добавлена отдельная кнопка перехода в `/teacher`, включая значок
  для мобильной версии. Обычным ученикам она не показывается; URL и API независимо
  проверяют права, скрытие кнопки не используется как защита.
- Созданный по запросу аккаунт — **Website User**, роли проверяющего и LMS Student.
  Доступ к `/desk` закрыт. System User администратора имеет другой сценарий входа:
  Frappe может направить его в Desk. Поэтому проверка под Administrator не заменяет
  проверку под обычным пользователем сайта.
- Почты нет: приглашение не отправлялось. Установка пароля передаётся приватной
  одноразовой ссылкой с обычным сроком Frappe; никаких паролей/ссылок в git нет.

## Проблемы, которые остаются

1. **Синхронизация и границы аккаунтов.** Companion и план Academy используют общие
   для браузера ключи `quran-companion-prototype-v4` и `allim-academy-plan-v1`.
   Вход/выход не переносит и не разделяет историю по пользователю. Для нескольких
   людей на одном устройстве это принципиальное ограничение.
2. **Учебный сценарий ещё не наполнен.** Зачислений, групп, живых занятий и сданных
   заданий сейчас 0. Карточка «От алифа до Аль-Фатихи» ведёт на статью, не на готовую
   опубликованную программу. Нельзя объявлять расписание, домашние задания и
   обратную связь готовыми только по наличию карточек интерфейса.
3. **LMS-интеграцию нужно проверить на реальных правах.** Academy запрашивает
   Enrollment, Batch Enrollment, Course и Batch через `/api/resource`. Для ученика
   зачисления ограничены `if_owner`, а Course не имеет общей student-read роли.
   Административное зачисление и загрузка описания курса требуют отдельного
   сквозного теста после публикации: фронтенд-фильтр `member` не заменяет права.
4. **Ошибки расписания замалчиваются.** `renderGuided` ловит исключение и оставляет
   пустой блок. «Следующее занятие» использует `future || live[0]` и может показать
   уже прошедшее; дата вычисляется без учёта часового пояса занятия.
5. **Гостевая LMS выдаёт JS-ошибку** `/api/method/frappe.apps.get_apps PermissionError`
   при первом desktop-входе. Оболочка и пустой каталог отображаются, но это не
   чистый гостевой сценарий. Исправление LMS не включалось в установку очереди.
6. **Обещания ИИ шире реализации.** Тафсир/планировщик действий — шаблоны, карточки
   ограничены; строгая диагностика пока текстовая. Нужны честные названия и
   обозначение покрытия до подключения проверенного расширенного функционала.
7. **Onboarding незавершён.** Сайт допускает регистрацию, LMS-настройка её отключает;
   нет исходящей почты для приглашений и восстановления доступа. Нужен один
   проверенный сценарий регистрации/входа/восстановления и возврата в Academy.
